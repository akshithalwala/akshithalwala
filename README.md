## Selected Engineering Work

### GCN Hardware Accelerator | RTL-to-GDSII
Implemented a parameterized SystemVerilog graph convolutional network accelerator with sparse COO aggregation, on-chip buffering, and an FSM-based controller. Verified simulation outputs against a golden reference, synthesized the design with Synopsys Design Compiler, and completed floorplanning, placement, CTS, and routing in Cadence Innovus.

### 4-Bit Ripple-Carry Adder | PPA Optimization
Designed and optimized a transistor-level ripple-carry adder using logical-effort-based sizing and critical-path optimization. Performed post-layout parasitic extraction and corner-based performance analysis.

### 16-Bit Clock-Gated Synchronous Up/Down Counter
Designed a synchronous counter using compact toggle flip-flops, Manchester carry-chain local clock generation, and clock gating to reduce unnecessary switching while improving speed and power-delay performance.

### CMOS / Custom IC Design
Worked on transistor-level CMOS circuit design, layout, simulation, and post-layout analysis using Cadence Virtuoso, HSPICE, and StarRC, including digital standard cells and analog IC coursework/projects.
