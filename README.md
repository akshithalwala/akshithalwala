## Projects

### Configurable 2D Mesh Network-on-Chip
- Designed a parameterized 2D mesh NoC in SystemVerilog using five-port routers, deterministic XY routing, input buffering, round-robin arbitration, and credit-based backpressure.
- Built self-checking traffic tests for routing, contention, and backpressure behavior, and evaluated latency, throughput, and congestion under different traffic conditions.
- Took the design through synthesis and physical implementation using Synopsys Design Compiler and Cadence Innovus, followed by post-route timing and PPA analysis.

### RTL-to-GDSII ASIC Implementation of a GCN Node-Classification Accelerator
- Implemented parameterized SystemVerilog RTL for sparse COO feature aggregation, on-chip buffering, and FSM-based control, and checked simulation outputs against a golden reference.
- Ran Tcl-driven synthesis in Synopsys Design Compiler and completed floorplanning, placement, clock-tree synthesis, and routing in Cadence Innovus using ASAP7.
- Performed post-route timing checks across evaluated PVT conditions and completed DRC/LVS verification.

### 4-Bit Adder Design with Power-Delay-Area Optimization
- Designed and optimized a transistor-level ripple-carry adder using logical-effort sizing and critical carry/XOR path tuning.
- Reached 45.3 µW power, 282 ps worst-case delay, and 39.7 µm² layout area, followed by parasitic extraction with StarRC and post-layout corner analysis in HSPICE.

### 16-Bit Clock-Gated Synchronous Up/Down Counter
- Designed a synchronous counter using compact toggle flip-flops and Manchester carry-chain local clock generation.
- Added clock gating to reduce unnecessary switching and achieved up to 55% faster operation with a 28% improvement in power-delay product in simulation.

### Chiplet and Package Co-Design for 2.5D Systems
- Worked on package-aware modeling and co-design for 2.5D chiplet systems, including interconnect, parasitic, thermal, and physical-design tradeoffs.
